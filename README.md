# Pook-lending-App
Pook Lending System is a lending management app designed to help organize borrower information, loan records, payment histories, and cash advances in one place. It supports daily, semi-monthly, and monthly payment schedules, with alerts to help staff monitor upcoming and overdue payments.
The app also includes admin and cashier workspaces, collection summaries, reports, and tools for reviewing payment references such as GCash transactions. Its goal is to make loan monitoring and daily collection recording clearer and easier for the lending team.
